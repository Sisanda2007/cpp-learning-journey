# cpp-learning-journey
Welcome to my C++ learning journey! This repository contains my practice programs as i develop my programming skills.

## Project: doubleArrays
A beginer C++ project focused on working with Arrays and performing calculations on their elements

## Features
- Finds the highest value in an array
- Finds the lowest value in an array
- Calculates the average of the array element
- Replaces any number less than 15 with 15

## Built with:
- C++
- Clion
- CMake

## Learning Goals
- Practice writing and organising c++ programs.
- Improve problem-solving and debugging skills.
- Build a foundation in functions, arrays , searching, and sorting.
- Learning how to use Git and GitHub to manage projects

## How to run
1. Clone or download this repository.
2. Open the project in Clion.
3. Make sure a compatible C++ compiler and CMake are configured.
4. Build the project.
